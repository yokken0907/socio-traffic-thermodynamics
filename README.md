# Socio-Traffic Thermodynamics (STT)

Claim-bounded repository package for:

**Socio-Traffic Thermodynamics: Congestion as a Non-Equilibrium Dissipative Structure Driven by Social Potential**  
Keiji Yoshimura, Independent Researcher, 2026.

This v0.3.0 package preserves the original STT public-gate manuscript and minimal ring-road validation materials, and adds a synthesis addendum on **risk-budgeted information release** in finite-capacity toy traffic networks.

## Scope

STT models traffic congestion as a non-equilibrium dissipative structure generated by socially driven agents moving on finite-capacity, finite-bandwidth transport networks.

The original numerical component is intentionally narrow: a stochastic Optimal Velocity (OV) ring-road simulation showing spontaneous stop-and-go wave formation without a fixed bottleneck.

The v0.3.0 synthesis addendum extends the repository with a claim-bounded toy-model audit sequence. It tests how high-sensitivity, high-frequency, synchronized information response can amplify overload, oscillation, and social cost in finite-capacity toy networks, and how low-rate, coarse-grained, or staged information release can be interpreted as a risk-budgeted buffering design.

## Reproduction of the original ring-road surrogate

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/stt_ring_reproducible.py --seed 20260416 --out results/stt_result_seed20260416.png
```

The original uploaded script did not fix a random seed. Therefore, exact pixel-level reproduction of the uploaded figure is not claimed. The repository preserves the original uploaded figure and provides a deterministic representative rerun script.

## v0.3.0 locked synthesis result

The v0.3.0 synthesis addendum locks the following claim-bounded toy-model result:

```text
Best frozen holdout policy: budget_common_u0.055_s0.00
Mean cost: 1.734372
No-information mean cost: 1.758804
Improvement vs no-information: 0.024432
Delta overload severity vs no-information: -0.004088
```

Interpretation: within the tested finite-capacity toy-network setting, high-sensitivity synchronized information response can amplify overload and social cost, while low-rate / risk-budgeted information release can improve average cost relative to a no-information null without increasing overload severity in the frozen holdout audit.

## Claim boundary

This repository supports only limited toy-model and surrogate-level claims. It does not claim:

- calibration to a real traffic network;
- real-world traffic forecasting accuracy;
- validated traffic-policy prescription;
- city-scale deployment readiness;
- universal decongestion methodology;
- safety-critical traffic-control readiness;
- proof that all congestion phenomena arise from the same mechanism;
- replacement for established traffic-flow, transportation-planning, or network-routing models.
