# Zenodo/GitHub registration notes

- Use the GitHub release tag exactly as written in `CITATION.cff` and `.zenodo.json`.
- Do not enter an existing external identifier manually.
- Let Zenodo generate a repository archive identifier automatically if a Zenodo release is created.
- Use the source-defined / other-open / license-in-repository option for licensing.
- Use the ZIP release asset for manual upload fallback if needed.
