# Project Consistency Audit

## Question

Does the uploaded manuscript `socio_traffic_thermodynamics_2026.pdf` correspond to the uploaded folder `STT_Simulation※渋滞.zip` as the same project?

## Verdict

**Yes, with one important scope qualification.**

The manuscript and the simulation folder are from the same STT project. The uploaded folder corresponds specifically to the numerical validation component of the paper: the stochastic Optimal Velocity ring-road simulation used to show spontaneous stop-and-go wave formation without a fixed bottleneck.

The folder is not a complete manuscript-source package. It originally contained:

- a Python virtual environment (`stt_env/`);
- a ring-road simulation script (`stt_ring.py`);
- an output image (`stt_result.png`).

The virtual environment is excluded from the cleaned repository package and replaced by `requirements.txt`.

## Manuscript correspondence

The manuscript introduces Socio-Traffic Thermodynamics (STT) as a framework in which traffic congestion is treated as a non-equilibrium dissipative structure generated by socially driven motion on finite-bandwidth networks.

The numerical validation section describes a one-lane periodic ring using a stochastic Optimal Velocity (OV) model with additive decentralized residual input:

```text
dx_i/dt = v_i
dv_i/dt = a * (V(h_i) - v_i) + sigma_sov * xi_i(t)
```

The uploaded script implements the same structure:

- `N = 30`
- `L = 300.0`
- `a = 1.0`
- `v_max = 10.0`
- `h_c = 5.0`
- `dt = 0.1`
- `steps = 3000`
- `sigma_sov = 0.5`
- periodic ring boundary condition
- stochastic additive driver noise
- space-time diagram output

The uploaded `stt_result.png` is the same kind of space-time diagram described as Figure 1 in the paper: cyan vehicle trajectories on a dark background, showing an initially near-homogeneous ring-road state that condenses into localized high-density stop-and-go structure.

## Scope qualification

The simulation folder supports the paper's Section 5 numerical validation only. It does not contain full LaTeX manuscript source, bibliography files, or a complete automated paper-reproduction pipeline.

## Repository action taken

This public-gate package preserves the manuscript PDF, the original simulation script, the original output image, and a cleaned reproducible script with explicit seed control. The original virtual environment is intentionally excluded.
